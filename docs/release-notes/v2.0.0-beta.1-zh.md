## Overview

v2.0.0-beta.1 是首个 v2 Beta 预发布版本。这份说明不代表已发布或已获准上线。镜像推送、GitHub Prerelease、更新通道写入和 Telegram 发送仍须维护者显式授权；候选验证不等于生产签署或完整 Web/API 兼容性认证。

## Highlights

### Features

- Embedded 采用单容器部署。`seakee/cpa-manager-plus:2.0.0-beta.1`（slim）不内置 CPA；`seakee/cpa-manager-plus:2.0.0-beta.1-full`（full）内置固定版本 CPA v8.0.55。`docker-compose.v2-embedded.yml` 通过 `@sha256` 固定 full 镜像，`embedded-release-pairing.json` 记录来源提交、两种镜像的摘要及 Full Web/API 契约配对。
- Native 仅支持 `linux/amd64`，资产名为 `cpa-manager-plus-native-v2_v2.0.0-beta.1_linux_amd64.tar.gz`，包含 Manager、Ingress、Runtime Supervisor 与固定的 CPA v8.0.55；不提供其余五个 1.x 平台包。
- `management.html` 继续作为 Lite 面板资产保留，供有意尝鲜的用户按明确的 Beta 版本地址使用。
- 六项最终资产为上述 Native 包、`management.html`、`docker-compose.v2-embedded.yml`、`embedded-release-pairing.json`、schema-2 `release-info.json` 与 `checksums.txt`。

### Fixes

- 发布工具只在显式启用 Beta 后生成 v2 发布元数据、更新 v2 Beta 通道；不接受 v2 Stable 或 RC。演练不会向 Registry 或 GitHub 写入。

## Upgrade Notes

- 不建议用本预发布版本替换生产中的 1.x。`releases/latest`、`releases/latest/download/management.html` 和 `install-cpamp.sh` 均保持 1.x Stable 的行为，不会将用户自动引导至 v2。
- 1.x 到 v2 不是单二进制原地替换升级。迁移前须按[升级指南](https://cpamp-docs.seakee.dev/next/operations/update.html)停机、备份数据库及 WAL/SHM、`data.key` 和 `usage-archives/`，并准备恢复备份的回滚路径。最低迁移起点记录为 v1.14.10，不表示旧版自动升级器能够执行 v2 迁移。
- v2 使用独立的 `update-index-v2.json`（`schema_version: 2`），只填充 `channels.beta`；`stable` 和 `rc` 为 `null`。1.x 的 `update-index.json`、`stable-version.txt` 和 Docker 别名均保持不变。
- Embedded 与 Native 首个 Beta 仅支持 linux/amd64 和 CPA v8.0.55。安装前请阅读版本固定的部署及升级文档，勿使用 1.x 默认安装器安装本 Beta。
