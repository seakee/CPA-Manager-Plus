## Overview

v2.0.0-beta.1 是首个 v2 Beta 预发布的说明草案，目前仅用于 DRY_RUN 演练，不代表已经发布或已获准上线。真实 Registry 推送、GitHub Prerelease、通道写入和 Telegram 发送仍须维护者显式授权（Gate M3–M5）；候选验证不等于生产签署或完整 Web/API 兼容性认证。

## Highlights

### Features

- Embedded 部署由 Manager、Ingress、Runtime 三个容器组成；使用 `docker-compose.v2-embedded.yml` 的不可变镜像 Digest，并通过 `embedded-release-pairing.json` 记录来源提交、三镜像与 Full Web/API 契约配对。
- Native 仅支持 `linux/amd64`，资产名为 `cpa-manager-plus-native-v2_v2.0.0-beta.1_linux_amd64.tar.gz`，包含 Manager、Ingress、Runtime Supervisor 与固定的 CPA v8.0.55；不提供其余五个 1.x 平台包。
- `management.html` 继续作为 Lite 面板资产保留，供有意尝鲜的用户按明确的 Beta 版本地址使用。
- 六项最终资产为上述 Native 包、`management.html`、`docker-compose.v2-embedded.yml`、`embedded-release-pairing.json`、schema-2 `release-info.json` 与 `checksums.txt`。

### Fixes

- 发布演练对 v2 stable、RC 与真实发布保持拒绝；仅显式开启 dry-run 与 Beta opt-in 后允许检查 v2 Beta 草案和候选资产。

## Upgrade Notes

- 这是预发布草案，不建议替换生产中的 1.x。`releases/latest` 与 `releases/latest/download/management.html` 保持 1.x Stable；`install-cpamp.sh` 默认行为也保持 1.x，不自动迁移到 v2。
- 1.x 到 v2 不是单二进制原地替换升级。迁移前须按运维文档停机、备份数据库及 WAL/SHM、`data.key` 和 `usage-archives/`，并准备恢复备份的回滚路径。最低迁移起点记录为 v1.14.10，不表示旧版自动升级器能够执行 v2 迁移。
- Beta 目标使用 schema_version 2；顶层更新索引保持 schema_version 1，演练只允许移动 `channels.beta`，不得改变 stable、rc 或镜像别名。
- Embedded 与 Native 首个 Beta 仅支持 linux/amd64 和 CPA v8.0.55。安装前请阅读版本固定的部署及升级文档，勿使用 1.x 默认安装器安装本 Beta。
