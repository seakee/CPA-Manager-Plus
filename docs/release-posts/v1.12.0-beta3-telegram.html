🚀 8 月 11 日 · v1.12.0-beta3 ✨ 更新内容 • Accounts 在提前或计划额度重置后会保留正确的当前与上一周期用量，周期标签也更准确。 • Accounts 在深链凭证加载和详情抽屉重开时会重新获取额度用量，避免出现空白或旧数据。 • 慢速兼容用量下载不再长期占用 SQLite 读取器，WAL 检查点可以及时推进。 • USD 费用在监控、分析和账户用量界面统一显示三位小数。 • 日志入口默认可见，请求日志可在可视化配置中直接管理。 • 插件被明确禁用时不再显示插件导航。 • 系统信息改用更清晰的内核术语，并链接到当前 CPAMP 在线文档。 ⚠️ 注意事项 • 这是预发布版本；稳定 Docker 标签和 latest 不会更新，请使用 v1.12.0-beta3 对应的镜像或发布资产。 • 当兼容接口 /v0/management/usage 的配置上限超过 50,000 条时，将返回最新 50,000 条；/v0/management/usage/export 仍遵循原配置上限。 • Manager Server 会自动添加非破坏性的额度周期查询索引，无需手工迁移或重写数据。
