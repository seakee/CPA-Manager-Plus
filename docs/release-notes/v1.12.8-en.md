## Overview

v1.12.8 focuses on making Accounts quota information easier to discover and historical usage easier to read, while correcting API-key analytics filters, OAuth credential synchronization, and quota-lifecycle boundary handling. Users can open the complete quota details directly from a credential row and still reach exact values behind compact history metrics; synthetic API-key groups no longer pollute key-specific analytics actions; and existing quota state remains correctly scoped when a reset is near or a new OAuth credential is added.

## Highlights

### Features

- Accounts credential-list history and quota regions now open the selected credential directly on its Quota details; standard interval windows remain in the list while model-scoped and other quota items stay available in details.

### Fixes

- Accounts history uses shared compact number and USD formatting, while hover and assistive technology still expose exact values and the history grid can size to its content.
- Usage Analytics retains the full aggregate contribution of synthetic fallback API-key groups while excluding synthetic IDs from client-key filters, trends, heatmaps, and drill-down actions.
- Adding a same-provider OAuth credential no longer clears valid quota for existing credentials; different auth indexes in the same auth file remain independent, and failed reloads preserve existing evidence.
- Fixed and calendar quota windows now tolerate up to 60 seconds of provider boundary jitter by closing the previous cycle at its scheduled end and starting the next cycle without overlapping attribution.
- Provisional zero-use Codex API snapshots no longer establish or reset a quota cycle until confirmed evidence arrives.

## Upgrade Notes

- This release adds no SQLite schema, migration, or backfill; usage_events are not rewritten, and existing quota cycles are corrected from new evidence during the next normal observation or manual refresh.
- A newly added same-provider OAuth credential may wait for its normal quota refresh before showing new quota; valid quota for existing credentials is retained.
- The Accounts list intentionally shows standard interval windows by default; open the credential's Quota details to inspect model-scoped or other quota items.
