# CPA Manager Plus v2.0.0-beta.1

> [中文 ->](https://github.com/seakee/CPA-Manager-Plus/blob/v2.0.0-beta.1/docs/release-notes/v2.0.0-beta.1-zh.md)

## Overview

v2.0.0-beta.1 is the first v2 Beta prerelease draft. It is currently used only for DRY_RUN rehearsal, not a claim that publication or production deployment has been authorized. Registry pushes, GitHub Prerelease publication, channel writes and Telegram delivery still require explicit maintainer authorization (Gates M3–M5). Candidate verification is not a signed production receipt or complete Web/API compatibility certification.

## Highlights

### Features

- Embedded uses three containers: Manager, Ingress and Runtime. `docker-compose.v2-embedded.yml` pins immutable image digests; `embedded-release-pairing.json` binds the source commit, three images and Full Web/API contract metadata.
- Native supports only `linux/amd64`. `cpa-manager-plus-native-v2_v2.0.0-beta.1_linux_amd64.tar.gz` contains Manager, Ingress, Runtime Supervisor and pinned CPA v8.0.55. The other five 1.x platform packages are not included.
- `management.html` remains the Lite panel asset for users explicitly opting into the version-pinned Beta download.
- The six final assets are that Native archive, `management.html`, `docker-compose.v2-embedded.yml`, `embedded-release-pairing.json`, schema-2 `release-info.json` and `checksums.txt`.

### Fixes

- Rehearsal rejects v2 stable, RC and real publication. Both explicit dry-run and Beta opt-in are required to validate v2 Beta drafts and candidate assets.

## Upgrade Notes

- This prerelease draft should not replace a production 1.x installation. `releases/latest` and `releases/latest/download/management.html` remain on 1.x Stable; `install-cpamp.sh` also retains its 1.x defaults and does not migrate users to v2.
- Moving from 1.x to v2 is not an in-place single-binary replacement. Stop services and back up databases including WAL/SHM, `data.key` and `usage-archives/`, then prepare a restore-based rollback according to the [upgrade guide](https://cpamp-docs.seakee.dev/next/en/operations/update.html). The recorded minimum migration starting point is v1.14.10; this does not authorize an old updater to perform v2 migration.
- The Beta channel target uses schema_version 2 while the index root remains schema_version 1. Rehearsal may move only `channels.beta`, never stable, rc or image aliases.
- The first Embedded and Native Beta supports linux/amd64 and CPA v8.0.55 only. Read the version-pinned deployment and upgrade documentation; do not use the default 1.x installer to install this Beta.
