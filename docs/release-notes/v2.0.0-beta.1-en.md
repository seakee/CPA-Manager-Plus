# CPA Manager Plus v2.0.0-beta.1

> [中文 ->](https://github.com/seakee/CPA-Manager-Plus/blob/v2.0.0-beta.1/docs/release-notes/v2.0.0-beta.1-zh.md)

## Overview

v2.0.0-beta.1 is the first v2 Beta prerelease. These notes do not imply that publication or production deployment has been authorized. Registry pushes, GitHub Prerelease publication, channel writes, and Telegram delivery still require explicit maintainer authorization. Candidate verification is not a signed production receipt or complete Web/API compatibility certification.

## Highlights

### Features

- Embedded runs in one container. `seakee/cpa-manager-plus:2.0.0-beta.1` (slim) does not bundle CPA; `seakee/cpa-manager-plus:2.0.0-beta.1-full` (full) bundles pinned CPA v8.0.55. `docker-compose.v2-embedded.yml` pins the full image with `@sha256`, and `embedded-release-pairing.json` binds the source commit, both image digests, and the Full Web/API contract metadata.
- Native supports only `linux/amd64`. `cpa-manager-plus-native-v2_v2.0.0-beta.1_linux_amd64.tar.gz` contains Manager, Ingress, Runtime Supervisor and pinned CPA v8.0.55. The other five 1.x platform packages are not included.
- `management.html` remains the Lite panel asset for users explicitly opting into the version-pinned Beta download.
- The six final assets are that Native archive, `management.html`, `docker-compose.v2-embedded.yml`, `embedded-release-pairing.json`, schema-2 `release-info.json` and `checksums.txt`.

### Fixes

- Release tools require explicit Beta opt-in to generate v2 release metadata and update the v2 Beta channel. They reject v2 Stable and RC, and dry runs do not write to the registry or GitHub.

## Upgrade Notes

- Do not replace a production 1.x installation with this prerelease. `releases/latest`, `releases/latest/download/management.html`, and `install-cpamp.sh` retain their 1.x Stable behavior and do not move users to v2.
- Moving from 1.x to v2 is not an in-place single-binary replacement. Stop services and back up databases including WAL/SHM, `data.key` and `usage-archives/`, then prepare a restore-based rollback according to the [upgrade guide](https://cpamp-docs.seakee.dev/next/en/operations/update.html). The recorded minimum migration starting point is v1.14.10; this does not authorize an old updater to perform v2 migration.
- v2 uses a separate `update-index-v2.json` (`schema_version: 2`). Only `channels.beta` is populated; `stable` and `rc` are `null`. The 1.x `update-index.json`, `stable-version.txt`, and Docker aliases stay unchanged.
- The first Embedded and Native Beta supports linux/amd64 and CPA v8.0.55 only. Read the version-pinned deployment and upgrade documentation; do not use the default 1.x installer to install this Beta.
