## Overview

v1.14.3 是 v1.14.2 的稳定性补丁版本，继续遵守 1.x 功能冻结边界，集中处理三个已经确认的兼容性与稳定性问题：Usage Maintenance 归档清理在 SQLite 瞬时写争用下可能反复中断、CPA v8 配置布局变化导致可视化配置读取/写入不正确，以及 Safari / iOS 缺少兼容站点图标的问题。

归档清理现在会区分瞬时 SQLite `BUSY` / `LOCKED` 与真实派生状态失败：已经提交且覆盖目标范围的安全状态不会再被瞬时争用错误污染，但重建、回填、真实失败或覆盖不足仍保持 fail-closed。可视化配置编辑器补齐 CPA v8 canonical path、历史别名、YAML merge / alias 与运行时能力边界，同时继续兼容 legacy 配置。Web 面板则新增 `favicon.ico` 与 `apple-touch-icon.png`，Full Mode 直接提供根路径资源，轻量面板保持单文件分发并在当前 Safari / iOS 中使用内嵌 fallback。

## Highlights

### Fixes

- 修复 Usage Maintenance 归档清理在已经具备安全派生覆盖时，因瞬时 SQLite `BUSY` / `LOCKED` 把有效状态错误标记为失败、导致清理频繁中断的问题；真实失败、重建/回填状态和覆盖不足仍然阻止删除原始用量。（Manager Server）
- 完善 CPA v8 可视化 YAML 配置兼容：按 CPA 的字段存在性与优先级读取 canonical path、历史 v8 alias 和 legacy path，并在真实 v8 布局中写回 canonical path；legacy-only 配置继续保持原路径行为。（Web / CPA compatibility）
- 补齐 YAML alias、`<<` merge key、部分混合布局、Management Key 保留/清除、Commercial Mode 持久化，以及 Codex `identity-confuse` 在不同 CPA v8 运行时版本下的能力边界。（Web / CPA compatibility）
- 增加多尺寸 `favicon.ico` 与 180×180 Apple Touch Icon；Full Mode 通过 Manager Server 提供固定根路径资源，并限制为 GET / HEAD。（Web / Manager Server）
- 轻量 `management.html` 继续保持单文件分发；当前 Safari / iOS 在根路径资源不是 CPAMP 图标时切换到字节一致的内嵌 Data URL，无需 CPA 下载额外静态文件。（Web / CPA lightweight panel）

### Docs / CI

- 更新中英文轻量面板、反向代理、FAQ 与升级文档，补充 `/favicon.ico`、`/apple-touch-icon.png` 的同域反代说明。
- 发布与 PR 检查增加 Web 图标资源完整性校验，确保 Vite / Go 二进制资源及最终单文件 fallback 保持一致。

## Upgrade Notes

- 无需数据库迁移，也无需修改现有 CPAMP 配置。
- 使用 Usage Maintenance 的实例无需调整归档参数；清理安全门仍要求目标范围已经被当前 schema / revision 的派生数据完整覆盖。
- CPA v8 用户可继续使用现有可视化配置页；本版本不会新增 1.x 配置项，只修复已有字段的读取和写入映射。
- 使用自定义同域反向代理且希望兼容旧版 Safari / iOS 根路径图标时，应将 `/favicon.ico` 与 `/apple-touch-icon.png` 路由到 CPAMP Manager Server；当前 Safari / iOS 的轻量面板仍可使用内嵌 fallback。
- Safari 18 及更早版本对 Data URL 图标支持不稳定，因此仅使用 CPA 轻量面板时不保证自定义主屏幕图标；Full Mode 不受此限制。
- 完整 Muse / Meta 功能的 CPA 基线继续为 **v7.3.4+**；本版本没有提高最低兼容基线。
